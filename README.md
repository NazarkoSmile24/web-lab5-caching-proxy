# Лабораторна робота №5

## Кешуючий проксі-сервер на Node.js

Автор: Назар Цепух.

Мета роботи — навчитися створювати HTTP-сервер-посередник,
який отримує картинки з http.cat, зберігає їх у кеші на диску
та повертає з кешу під час повторних запитів.

Технології: Node.js, http, fs/promises, commander, superagent.

Заплановані методи:
- GET — отримання картинки;
- PUT — збереження або заміна картинки;
- DELETE — видалення картинки з кешу.
